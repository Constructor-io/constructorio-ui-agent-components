# Constructor Agent Components UI

React components for Constructor's agentic experiences. **Agent Overview** streams AI-generated category suggestions for a shopping intent, then product recommendation sections.

```bash
npm install @constructor-io/constructorio-ui-agent-components
```

## How these docs are organised

- **Guides** show how to do something. Start with the [Integration Guide](./?path=/docs/guides-integration-guide--docs).
- **Components & Utilities** is the reference for everything the package exports.
