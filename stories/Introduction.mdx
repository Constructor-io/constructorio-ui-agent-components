# Constructor Agent Components UI

React components for Constructor's agentic experiences, in one package.

```bash
npm install @constructor-io/constructorio-ui-agent-components
```

## Components

Each component has its own section: an Integration Guide to start with, guides for everything else, and **Components & Utilities**, the reference for its exports.
