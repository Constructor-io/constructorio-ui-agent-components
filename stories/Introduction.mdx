# Constructor Agent Components UI

React components for Constructor's agentic experiences, in one package.

```bash
npm install @constructor-io/constructorio-ui-agent-components
```

## Components

Each component has its own section: an Integration Guide to start with, guides for everything else, and **Components & Utilities**, the reference for its exports.

## Every component

- Import the styles once: `@constructor-io/constructorio-ui-agent-components/styles.css`.
- Needs Node.js 20 or later to build, and React and React DOM 16.14 or later (for the JSX runtime).
- Peer dependencies: `@constructor-io/constructorio-ui-components` ^1.3.0 and `@constructor-io/constructorio-client-javascript` ^2.76.0.
- Setup problems: see the [FAQ](./?path=/docs/faq--docs).

Stuck on a use case? Contact your Constructor Integration Engineer.
