# Constructor Agent Components UI

React components for Constructor's agentic experiences. **Agent Overview** streams an AI Overview for a search: a short AI-written summary and the products picked for it, above your search results.

```bash
npm install @constructor-io/constructorio-ui-agent-components
```

## How these docs are organised

- Each component has its own section in the sidebar, such as **Agent Overview**.
- In a component's section, the guides show how to do something; start with its [Integration Guide](./?path=/docs/agent-overview-integration-guide--docs). **Components & Utilities** is the reference for what it exports.
- **FAQ** covers setup problems for every component.
