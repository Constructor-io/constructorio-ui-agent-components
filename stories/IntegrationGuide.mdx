# Integration Guide

This guide walks you through integrating **CioAgentOverview** into your React application.

---

## Prerequisites

- Node.js >= 20
- React >= 16.12.0
- React DOM >= 16.12.0

## Headless Usage with `useAgentOverview`

For full control over the UI, use the hook directly:

```tsx
import { useAgentOverview } from '@constructor-io/constructorio-ui-agent-components';
import '@constructor-io/constructorio-ui-agent-components/styles.css';

function CustomAgentUI() {
  const {
    phase,
    categories,
    categoryDescription,
    sections,
    selectCategory,
    isLoading,
    error,
  } = useAgentOverview({
    apiKey: 'YOUR_API_KEY',
    intent: 'I want to buy casual style',
    domains: { suggestions: 'searchbar', results: 'explorer' },
  });

  if (error) return <div>Error: {error.message}</div>;
  if (isLoading && categories.length === 0) return <div>Loading...</div>;

  return (
    <div>
      {phase === 'categories' && (
        <ul>
          {categories.map((cat) => (
            <li key={cat.title}>
              <button type="button" onClick={() => selectCategory(cat)}>
                {cat.title}
              </button>
            </li>
          ))}
        </ul>
      )}
      {phase === 'products' &&
        sections.map((section) => (
          <div key={section.title}>
            <h2>{section.title}</h2>
            <p>{section.description}</p>
            {section.products.map((product) => (
              <span key={product.itemName}>{product.itemName}</span>
            ))}
          </div>
        ))}
    </div>
  );
}
```

## Standalone (Non-React) Usage

For non-React environments, use the standalone bundle:

```html
<div id="cio-agent-overview"></div>
<script src="path/to/constructorio-ui-agent-components.standalone.js"></script>
<script>
  CioAgentOverview.init({
    selector: '#cio-agent-overview',
    apiKey: 'YOUR_API_KEY',
    intent: 'I want to buy casual style',
    domains: {
      suggestions: 'searchbar',
      results: 'explorer',
    },
  });
</script>
```
