# FAQ

## `Module parse failed: Unexpected token`

Your bundler can't parse the ESNext build. Resolve the package with `require` to get the CommonJS build, which is ES2015.

## ESLint: `Unable to resolve path to module '…/styles.css'`

`eslint-plugin-import` can't resolve package `exports` ([#1868](https://github.com/import-js/eslint-plugin-import/issues/1868), [#1810](https://github.com/import-js/eslint-plugin-import/issues/1810)). Disable the rule for that line with `// eslint-disable-line`.

## Agent Overview: nothing renders

Simple keyword searches, such as a brand or a product name, have no AI Overview promise in the search response, so there's no request and nothing renders. A promise the agent declines (a 204) renders nothing and calls `callbacks.onNoOverview`; a failed request renders nothing and calls `callbacks.onError`. Check too that AI Overview is turned on for your index (descriptive searches have `agentic_promises` in the search response), and that you pass the response's `agentic_promises`, not the whole response.

## Agent Overview: it keeps reloading

A promise with a new `callback_url` or `body` starts a new request; a new but equal one doesn't. Each search response has its own `callback_url`, so pass the response for the search on screen, not one fetched again on every render.
