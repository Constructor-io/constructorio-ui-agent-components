# Integration Guide

Agent Recommendations is a recommendations pod for a product page: an AI-written title, a carousel of products picked for the product being viewed, and options such as "Slim cardholders" that reload the pod for one interest.

1. **Install**

   ```bash
   npm install @constructor-io/constructorio-ui-agent-components
   ```

2. **Render it** on the product page.

   ```jsx
   import { CioAgentRecommendations } from '@constructor-io/constructorio-ui-agent-components';
   import '@constructor-io/constructorio-ui-agent-components/styles.css';

   <CioAgentRecommendations
     apiKey="YOUR_API_KEY"
     itemId={product.id}
     itemName={product.name}
     strategy="complementary_pod"
   />;
   ```

   Ask your Integration Engineer which strategies your key has, such as `complementary_pod` or `alternatives_pod`. A new `itemId`, `variationId` or `strategy` starts a new pod. The pod renders nothing when the request fails or returns no products, so the page looks as it did without it.

3. **Share your client.** The pod sends the shopper's identity so it can personalize. If your site already has a Constructor JS client, pass it as `cioJsClient` so the pod also sends its `userId` and segments.

4. **Handle clicks.** See [Callbacks](?path=/docs/agent-recommendations-callbacks--docs).

5. **Style it.** See [Customization](?path=/docs/agent-recommendations-customization--docs).

6. **Check the tracking.** The pod sends Constructor's behavioral events itself. See [Tracking](?path=/docs/agent-recommendations-tracking--docs). Running a test? See [A/B Testing](?path=/docs/agent-recommendations-ab-testing--docs).

7. **Need your own markup?** Replace parts of the pod, or all of it. See [Custom UI](?path=/docs/agent-recommendations-custom-ui--docs).
