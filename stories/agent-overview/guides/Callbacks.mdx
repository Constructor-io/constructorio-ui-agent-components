# Callbacks

## Tracking

Agent Overview doesn't send Constructor behavioral events yet. To measure it now, send your own from these callbacks.

## Callbacks

```jsx
<CioAgentOverview
  agenticPromises={searchResponse.response.agentic_promises}
  callbacks={{
    onProductClick: (event, product, section) =>
      myAnalytics.track('product_click', {
        name: product.itemName,
        category: section.title,
      }),
    getProductUrl: (product) => `${product.url}?ref=ai-overview`,
    onNoOverview: () => setOverviewSlotVisible(false),
    onError: (error) => myLogger.warn('AI Overview failed', error),
  }}
/>
```

<Markdown>
  {`
| Callback | Signature | Fires when |
|---|---|---|
| \`onProductClick\` | \`(event, product, section)\` | A product card is clicked, with the product set it came from. The card is a link: call \`event.preventDefault()\` to navigate yourself |
| \`getProductUrl\` | \`(product) => string\` | Each product card renders its link. Default \`product.url\` |
| \`onNoOverview\` | \`()\` | Search promised an overview and the agent turned it down. Not for a search without a promise, which makes no request |
| \`onError\` | \`(error)\` | The overview fails, with \`{ status, code, message }\`. \`status\` is 0 when there was no response |
`}
</Markdown>

In both of the last two cases nothing renders. See [when nothing renders](?path=/docs/faq--docs#agent-overview-nothing-renders).
