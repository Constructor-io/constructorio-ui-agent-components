# Callbacks

```jsx
<CioAgentOverview
  agenticPromises={searchResponse.response.agentic_promises}
  callbacks={{
    onProductClick: (event, product, section) =>
      myAnalytics.track('product_click', {
        name: product.itemName,
        category: section.title,
      }),
    getProductUrl: (product) => `${product.url}?ref=ai-overview`,
    onNoOverview: () => setOverviewSlotVisible(false),
    onError: (error) => myLogger.warn('AI Overview failed', error),
  }}
/>
```

<Markdown>
  {`
| Callback | Called |
|---|---|
| \`onProductClick(event, product, section)\` | When a product card is clicked, with the product set it came from. The card is a link: call \`event.preventDefault()\` to navigate yourself |
| \`getProductUrl(product)\` | For each product card's link. Default \`product.url\` |
| \`onNoOverview()\` | When search promised an overview but the agent turned it down: a 204 (nothing produced) or a 422 (a query it finds unsuitable). The component renders nothing. Not called for a search without a promise, which makes no request |
| \`onError(error)\` | When the overview fails, with \`{ status, code, message }\`: any other status but 200, or a \`server_error\` while it streams, which hides products already shown. \`status\` is 0 when there was no response. The component renders nothing |
`}
</Markdown>
