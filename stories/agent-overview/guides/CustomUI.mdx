# Custom UI

`useAgentOverview` takes the component's props and returns the stream's state, so you render it yourself. See [useAgentOverview](?path=/docs/agent-overview-components-utilities-useagentoverview--docs).

```jsx
import {
  useAgentOverview,
  ProductCarousel,
} from '@constructor-io/constructorio-ui-agent-components';
import '@constructor-io/constructorio-ui-agent-components/styles.css';

function MyAgentOverview({ query }) {
  const { status, message, sections, viewRef } = useAgentOverview({
    apiKey: 'YOUR_API_KEY',
    query,
  });

  if (status === 'loading') return <p>Loading…</p>;
  if (status !== 'streaming' && status !== 'done') return null;

  return (
    <div className="cio-agent-overview-root" ref={viewRef}>
      <p>{message}</p>
      <ProductCarousel
        products={sections.flatMap((section) => section.products)}
      />
    </div>
  );
}
```

The hook sends the tracking events, with `viewRef` attached and `trackProductClick` called on clicks (see [Tracking](?path=/docs/agent-overview-tracking--docs)). It calls `callbacks.onNoOverview` and `callbacks.onError`, and ignores `theme`, `translations` and the other callbacks; pass them to the [components](?path=/docs/agent-overview-components-utilities-section-components--docs) you render. Those components are styled only inside a `cio-agent-overview-root` element.
