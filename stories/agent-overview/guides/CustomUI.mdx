# Custom UI

`useAgentOverview` takes the component's props and returns the stream's state, so you render it yourself. See [useAgentOverview](?path=/docs/agent-overview-components-utilities-useagentoverview--docs).

```jsx
import {
  useAgentOverview,
  ProductCarousel,
} from '@constructor-io/constructorio-ui-agent-components';
import '@constructor-io/constructorio-ui-agent-components/styles.css';

function MyAgentOverview({ searchResponse }) {
  const { status, message, sections, displayName } = useAgentOverview({
    agenticPromises: searchResponse.response.agentic_promises,
  });

  if (status === 'loading') return <p>Loading…</p>;
  if (status !== 'streaming' && status !== 'done') return null;

  return (
    <div className="cio-agent-overview-root">
      <span>{displayName}</span>
      <p>{message}</p>
      <ProductCarousel
        products={sections.flatMap((section) => section.products)}
      />
    </div>
  );
}
```

The hook uses only some props; see [useAgentOverview](?path=/docs/agent-overview-components-utilities-useagentoverview--docs). For the rest:

- **Components:** render the [product components](?path=/docs/agent-overview-components-utilities-product-components--docs) inside a `cio-agent-overview-root` element to get their styles, and pass them `translations`.
- **Theme:** the components take no `theme`. Set the `--cio-*` variables from the [theming table](?path=/docs/agent-overview-customization--docs#theming) on that root element's `style` instead.
- **Clicks:** `ProductCarousel`'s `onProductClick` is `(event, product)`, without the section. Find the product's section in `sections` if you need it.
