# Integration Guide

AI Overview adds an AI-written summary and a row of products above your search results. Your Constructor search decides which searches get one: its response carries `agentic_promises`, and a search that suits an overview has a promise for it. The component sends that promise and renders the overview. Keyword searches, such as a brand, usually have no promise and see no change.

1. **Check that it's on.** Ask your Integration Engineer to turn AI Overview on for your index. Then search a descriptive query, such as "gift for my dad who loves grilling", and look for `agentic_promises` in the search response.

2. **Install**

   ```bash
   npm install @constructor-io/constructorio-ui-agent-components
   ```

3. **Render it** between your search header and the first row of results, with the `agentic_promises` from the search response for the page.

   ```jsx
   import CioAgentOverview from '@constructor-io/constructorio-ui-agent-components';
   import '@constructor-io/constructorio-ui-agent-components/styles.css';

   <CioAgentOverview
     agenticPromises={searchResponse.response.agentic_promises}
   />;
   ```

   The component finds the promise whose `pod.id` is `search_ai_overview` and sends its `body`, unchanged, to its `callback_url`. Search wrote both for the query, filters and shopper it served, and the URL already carries your key and the shopper's identity, so there's nothing else to pass. Render your results as soon as search returns: the overview never holds them up.

4. **Expect nothing for some searches.** There's no request and nothing renders when the response has no AI Overview promise. A promise is not a guarantee: when the agent turns it down (a 204, or a 422 for a query it finds unsuitable, which some indexes send promises for), the component shows its loading card briefly, then renders nothing and calls `callbacks.onNoOverview`. When the request fails, or the agent fails while streaming, it renders nothing and calls `callbacks.onError`. See [Callbacks](?path=/docs/agent-overview-callbacks--docs).

5. **Style it.** See [Customization](?path=/docs/agent-overview-customization--docs).

6. **Need your own markup?** See [Custom UI](?path=/docs/agent-overview-custom-ui--docs).

## New searches

Pass each new search response's `agentic_promises`. A new search, or a filter that sends a new promise, aborts the overview still streaming, so an old overview never lands on new results. Re-rendering with the same response doesn't send it again.

## Without React

The JavaScript bundle includes React and the styles, and mounts the component into an element:

```js
import CioAgentOverview from '@constructor-io/constructorio-ui-agent-components/constructorio-ui-agent-components-standalone';

CioAgentOverview.init({
  selector: '#agent-overview',
  agenticPromises: searchResponse.response.agentic_promises,
});

// After the next search:
CioAgentOverview.update('#agent-overview', {
  agenticPromises: nextSearchResponse.response.agentic_promises,
});
```

It takes the same props. See [JavaScript Bundle](?path=/docs/agent-overview-components-utilities-javascript-bundle--docs) for `destroy`.
