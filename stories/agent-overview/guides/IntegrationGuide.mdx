# Integration Guide

`CioAgentOverview` renders AI Overview: an AI-written summary and a row of products above your search results. Your Constructor search decides which searches get one: its response carries `agentic_promises`, and a search that suits an overview has a promise for it. The component sends that promise and renders what comes back. Keyword searches, such as a brand, usually have no promise and see no change.

Steps 1–3 are all you need. Everything after is optional.

## 1. Turn it on

Ask your Integration Engineer to turn AI Overview on for your index. To check, search a descriptive query, such as "gift for my dad who loves grilling", and look for `agentic_promises` in the search response.

## 2. Install

```bash
npm install @constructor-io/constructorio-ui-agent-components
```

## 3. Render it above your results

Place it between your search header and the first row of results, with the `agentic_promises` from the search response for the page:

```jsx
import CioAgentOverview from '@constructor-io/constructorio-ui-agent-components';
import '@constructor-io/constructorio-ui-agent-components/styles.css';

export default function SearchResultsPage({ searchResponse }) {
  return (
    <>
      <CioAgentOverview
        agenticPromises={searchResponse.response.agentic_promises}
      />
      {/* your results */}
    </>
  );
}
```

<Canvas of={LayoutStories.MultiCategory} />

The component finds the promise whose `pod.id` is `search_ai_overview` and sends its `body`, unchanged, to its `callback_url`. Search wrote both for the query, filters and shopper it served, and the URL already carries your key and the shopper's identity, so there's nothing else to pass. Render your results as soon as search returns: the overview never holds them up.

Pass each new search response's `agentic_promises`. A new search, or a filter that sends a new promise, aborts the overview still streaming, so an old overview never lands on new results.

**Not using React?** The JavaScript bundle includes React and the styles, and takes the same props:

```js
import CioAgentOverview from '@constructor-io/constructorio-ui-agent-components/constructorio-ui-agent-components-standalone';

CioAgentOverview.init({
  selector: '#agent-overview',
  agenticPromises: searchResponse.response.agentic_promises,
});
```

## 4. Handle searches without an overview

Some searches render nothing. Use `callbacks.onNoOverview` to collapse space you kept for it, and `callbacks.onError` to log failures.

## 7. Check it works

Search a descriptive query. In the network tab, filter on `agent_insights`: a `POST` to the promise's `callback_url` answers 200 with an event stream, and the overview appears above your results. A keyword search such as a brand makes no such request. For problems, see the [FAQ](?path=/docs/faq--docs). For every prop, see [CioAgentOverview](?path=/docs/agent-overview-components-utilities-cioagentoverview--docs).
