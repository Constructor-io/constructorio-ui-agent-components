# Integration Guide

1. **Install**

   ```bash
   npm install @constructor-io/constructorio-ui-agent-components
   ```

2. **Render it** above your search results with the shopper's search.

   ```jsx
   import CioAgentOverview from '@constructor-io/constructorio-ui-agent-components';
   import '@constructor-io/constructorio-ui-agent-components/styles.css';

   <CioAgentOverview apiKey="YOUR_API_KEY" query={searchQuery} />;
   ```

   The overview comes from `POST /v1/agent_insights/search`. Ask your Integration Engineer to turn AI Overview on for your index. A blank `query` makes no request, and a new `query` starts over.

3. **Expect nothing for some searches.** Simple keyword searches, such as a brand, get no overview, and the component renders nothing. So does a failed request. `callbacks.onNoOverview` and `callbacks.onError` tell you when. See [Callbacks](?path=/docs/agent-overview-callbacks--docs).

4. **Style it.** See [Customization](?path=/docs/agent-overview-customization--docs).

5. **Need your own markup?** See [Custom UI](?path=/docs/agent-overview-custom-ui--docs).

## Page context

The overview assumes a search results page for `query`. Set `pageContext` when it isn't one:

```jsx
<CioAgentOverview
  apiKey="YOUR_API_KEY"
  query={searchQuery}
  pageContext={{ pageType: 'collection', searchTerm: 'summer' }}
/>
```

## Without React

The JavaScript bundle includes React and the styles, and mounts the component into an element:

```js
import CioAgentOverview from '@constructor-io/constructorio-ui-agent-components/constructorio-ui-agent-components-standalone';

CioAgentOverview.init({
  selector: '#agent-overview',
  apiKey: 'YOUR_API_KEY',
  query: 'gift for my dad who loves grilling',
});
```

It takes the same props. See [JavaScript Bundle](?path=/docs/agent-overview-components-utilities-javascript-bundle--docs) for `update` and `destroy`.
