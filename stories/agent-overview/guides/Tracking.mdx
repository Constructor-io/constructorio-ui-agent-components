# Tracking

`CioAgentOverview` sends the AI Overview's behavioral events itself, through the JavaScript client's agent tracker. They carry the client tag `cio-ui-agent-overview-<version>`, and so does the overview request, even when you pass your own `cioJsClient`.

<Markdown>
  {`
| Event | Sent when | Fields |
|---|---|---|
| \`trackAgentSubmit\` | The overview request gets a response | \`intent\` (the query) |
| \`trackAgentResultLoadStarted\` | The overview starts streaming | \`intent\`, \`intentResultId\`, \`threadId\` |
| \`trackAgentResultLoadFinished\` | The overview finishes streaming | \`intent\`, \`intentResultId\`, \`threadId\`, \`searchResultCount\` (products shown) |
| \`trackAgentResultView\` | One of a product set's cards is half on screen, once per set | \`intent\`, \`intentResultId\`, \`threadId\`, \`searchResultId\`, \`numResultsViewed\`, \`items\` |
| \`trackAgentResultClick\` | A product card is clicked | \`intent\`, \`intentResultId\`, \`threadId\`, \`searchResultId\`, \`itemId\`, \`itemName\`, \`variationId\` |
`}
</Markdown>

A search the endpoint turns down (a 422) sends only `trackAgentSubmit`. A stream that ends without products also sends the two load events, with a `searchResultCount` of 0, and then nothing shows. A tracking call that throws is logged to the console and doesn't stop the overview. JavaScript clients older than 2.91.0 leave `threadId` out of the events.

## Your own JavaScript client

A `cioJsClient` you pass sends events only if it was created with `sendTrackingEvents: true`. The client the component creates from `apiKey` already is.

## Custom UI

`useAgentOverview` sends submit and the load events on its own. For views and clicks, attach `viewRef` to the element that shows the products, and call `trackProductClick` when a product is clicked. Give each product's element the `cio-agent-overview-product-card` class, in product order, so a set's view waits until one of its own products is on screen; without it, every set counts as viewed once the element is half on screen. Products without a catalog id are left out of views and send no click.

```jsx
const { message, sections, viewRef, trackProductClick } = useAgentOverview({
  apiKey: 'YOUR_API_KEY',
  query,
});

<div ref={viewRef}>
  {sections.map((section) =>
    section.products.map((product) => (
      <a
        key={product.url}
        className="cio-agent-overview-product-card"
        href={product.url}
        onClick={() => trackProductClick(product, section)}
      >
        {product.itemName}
      </a>
    ))
  )}
</div>;
```

## Checking events

The JavaScript client drops events from browsers it treats as bots, including headless automation. In a real browser, they show in the network panel as `assistant_submit`, `assistant_result_load_start`, `assistant_result_load_finish`, `assistant_search_result_view` and `assistant_search_result_click`.
