# JavaScript Bundle

`CioAgentOverview` for pages without React. It includes React and the styles.

```js
import CioAgentOverview from '@constructor-io/constructorio-ui-agent-components/constructorio-ui-agent-components-standalone';

CioAgentOverview.init({
  selector: '#agent-overview',
  agenticPromises: searchResponse.response.agentic_promises,
});
// After the next search:
CioAgentOverview.update('#agent-overview', {
  agenticPromises: nextSearchResponse.response.agentic_promises,
});
CioAgentOverview.destroy('#agent-overview');
```

<Markdown>
  {`
| Method | What it does |
|---|---|
| \`init(options)\` | Mounts into \`options.selector\`, replacing any instance there. \`options\` are [\`CioAgentOverview\`'s props](?path=/docs/agent-overview-components-utilities-cioagentoverview--docs), plus \`selector\` and \`includeCSS\` (default \`true\`). Returns the element, or \`undefined\` if it wasn't found |
| \`update(selector, props)\` | Merges \`props\` into the instance's props and re-renders |
| \`destroy(selector?)\` | Unmounts one instance, or all of them |
| \`VERSION\` | The library version |
`}
</Markdown>
