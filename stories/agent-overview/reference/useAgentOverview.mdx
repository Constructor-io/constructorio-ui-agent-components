# useAgentOverview

Streams the AI Overview for a search. Takes [`CioAgentOverview`'s props](?path=/docs/agent-overview-components-utilities-cioagentoverview--docs); it uses `apiKey`, `cioJsClient`, `query`, `pageContext`, `callbacks.onNoOverview` and `callbacks.onError`. See [Custom UI](?path=/docs/agent-overview-custom-ui--docs).

```js
const {
  status,
  message,
  sections,
  resultId,
  threadId,
  error,
  viewRef,
  trackProductClick,
} = useAgentOverview(props);
```

<Markdown>
  {`
| Returns | Type | |
|---|---|---|
| \`status\` | \`'idle' \\| 'loading' \\| 'streaming' \\| 'done' \\| 'no-overview' \\| 'error'\` | \`idle\` without a query; \`loading\` until the stream opens; \`streaming\` while it arrives |
| \`message\` | \`string\` | The overview's text. Several messages are joined with a blank line |
| \`sections\` | \`IAgentOverviewSection[]\` | \`{ title, searchResultId, products }\`, one per product set, in the order they arrived |
| \`resultId\` | \`string \\| null\` | The overview's id, once the stream opens |
| \`threadId\` | \`string \\| null\` | The conversation thread the overview opened, if any |
| \`error\` | \`IAgentOverviewError \\| null\` | \`{ status, code, message }\` when \`status\` is \`error\` |
| \`viewRef\` | \`(node) => void\` | Attach to the element showing the products to send view events, one per set once one of its cards is on screen. See [Tracking](?path=/docs/agent-overview-tracking--docs) |
| \`trackProductClick\` | \`(product, section) => void\` | Sends a product's click event |
`}
</Markdown>

The message usually arrives before the products. A set whose products have no name or image is left out. If the stream fails after some products arrived, `status` is `done` with those products.
