# useAgentOverview

Streams the AI Overview that a search response promised. Takes [`CioAgentOverview`'s props](?path=/docs/agent-overview-components-utilities-cioagentoverview--docs); it uses `agenticPromises`, `callbacks.onNoOverview` and `callbacks.onError`. See [Custom UI](?path=/docs/agent-overview-custom-ui--docs).

```js
const { status, message, sections, resultId, threadId, error, displayName } =
  useAgentOverview(props);
```

<Markdown>
  {`
| Returns | Type | |
|---|---|---|
| \`status\` | \`'idle' \\| 'loading' \\| 'streaming' \\| 'done' \\| 'no-overview' \\| 'error'\` | \`idle\` without an AI Overview promise; \`loading\` until the stream opens; \`streaming\` while it arrives |
| \`message\` | \`string\` | The overview's text. Several messages are joined with a blank line |
| \`sections\` | \`IAgentOverviewSection[]\` | \`{ title, searchResultId, products }\`, one per product set, in the order they arrived |
| \`resultId\` | \`string \\| null\` | The overview's id, once the stream opens |
| \`threadId\` | \`string \\| null\` | The conversation thread the overview opened, if any |
| \`error\` | \`IAgentOverviewError \\| null\` | \`{ status, code, message }\` when \`status\` is \`error\` |
| \`displayName\` | \`string \\| null\` | Search's label for the overview (the promise's \`pod.display_name\`, e.g. "AI Overview") |
`}
</Markdown>

The message usually arrives before the products. A set whose products have no name or image is left out. A `server_error` ends in `error`, even after products arrived. If the connection drops after some products arrived, `status` is `done` with those products.
