# Customization

## Styling

Import `@constructor-io/constructorio-ui-agent-components/styles.css`. Without it the component renders unstyled. The JavaScript bundle includes the styles unless you pass `includeCSS: false`.

Every rule is scoped to `.cio-agent-overview-root`, and every element has a `cio-agent-overview-` class to style against.

The component fills its container's width:

<Canvas of={LayoutStories.SmallContainer} />

## Theming

`theme` sets CSS custom properties on the root.

```jsx
<CioAgentOverview
  theme={{
    fontFamily: 'Inter, sans-serif',
    primaryColor: '#1a1a1a',
    spacingMd: '16px',
  }}
/>
```

## Translations

```jsx
<CioAgentOverview
  translations={{ 'CioAgentOverview.section.viewMore': 'Ver todo' }}
/>
```

<Markdown>
  {`
| Key | Default |
|---|---|
| \`CioAgentOverview.section.aiBadge\` | Generated with AI |
| \`CioAgentOverview.categories.viewSuggestions\` | View suggestions |
| \`CioAgentOverview.section.viewMore\` | View More |
| \`CioAgentOverview.skeleton.thinking\` | Thinking |
| \`CioAgentOverview.error.message\` | Something went wrong. Please try again. |
| \`CioAgentOverview.carousel.previous\` | Show previous items |
| \`CioAgentOverview.carousel.next\` | Show next items |
| \`CioAgentOverview.carousel.label\` | Products |
| \`CioAgentOverview.categories.carouselLabel\` | Categories |
`}
</Markdown>

An empty string hides a visible string. The last four are read only by screen readers, so an empty string falls back to the default. Content from the API, such as titles and product names, isn't translated.
